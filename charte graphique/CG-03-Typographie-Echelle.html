02 — Échelle de taille

7 niveaux. Pas un de plus.

L'échelle est délibérément compacte. Chaque niveau est justifié par un usage précis. Utiliser un niveau hors de son contexte prescrit est une violation de la charte. La cohérence de l'échelle est ce qui crée la densité maîtrisée.

Token Taille Line-h. Poids std Tracking Usage — exemple rendu

text-xl 22px 1.2 600 −0.03em Valeur KPI principale
text-lg 18px 1.3 600 −0.025em Titre de section principale

03 — Poids typographiques

5 poids. Chacun à sa place.

La hiérarchie visuelle se construit principalement via les poids et les tailles — pas par la couleur. On n'utilise jamais un poids par défaut "parce que ça va bien" : chaque poids a sa liste de cas d'usage.

05 — DM Mono · Usages exclusifs

Quand utiliser la police monospace

DM Mono est réservée aux éléments de données techniques. Son usage hors de ces cas constitue une violation de la charte. Elle n'est jamais utilisée pour du contenu textuel courant — même pour "faire technique".

06 — Règles techniques

Ce qui s'applique partout, toujours

Ces règles techniques complètent l'échelle. Elles garantissent la cohérence du rendu sur tous les navigateurs et résolutions.

Antialiasing obligatoire
Toute l'interface utilise le rendu antialiasé subpixel. Jamais de texte pixelisé. S'applique à body et se propage.
body {
-webkit-font-smoothing: antialiased;
-moz-osx-font-smoothing: grayscale;
}
Pas de text-transform uppercase sur le contenu
Le uppercase est réservé aux labels mono de section et aux badges techniques. Jamais sur les titres, boutons, ou corps de texte.
/* ✓ Autorisé */
.section-label { text-transform: uppercase; }
/* ✗ Interdit */
.page-title { text-transform: uppercase; }
Taille minimale absolue : 10px
Aucun texte en dessous de 10px dans l'interface. Pas même les labels les plus discrets. Accessibilité WCAG 1.4.4.
/* Font-size minimum absolu */
--text-xs: 10px;

/* Jamais : */
font-size: 8px; /* ✗ Interdit */
Letter-spacing négatif sur les grands titres
Au-delà de 18px, appliquer systématiquement un tracking négatif pour compenser l'espacement optique. Plus le titre est grand, plus le tracking est serré.
28px → letter-spacing: -0.035em
22px → letter-spacing: -0.030em
18px → letter-spacing: -0.025em
14px → letter-spacing: -0.010em
≤13px → letter-spacing: 0
Line-height adapté à la taille
Les grands textes ont un line-height serré. Les petits textes ont un line-height généreux pour la lisibilité. Jamais de line-height: 1 sur du corps de texte.
28px → line-height: 1.15
18px → line-height: 1.30
13px → line-height: 1.65
11px → line-height: 1.55
10px → line-height: 1.40
Truncation sur une ligne (ellipsis)
Les noms de documents dans les tables sont toujours tronqués. Ne jamais laisser un texte casser la mise en page avec overflow visible.
.truncate {
overflow: hidden;
text-overflow: ellipsis;
white-space: nowrap;
max-width: 100%;
}
07 — Export tokens

Variables CSS typographiques — À ajouter dans globals.css

CSS — globals.css · Typographie CG-03
/* ═══════════════════════════════════════════════════
   TYPOGRAPHIE — Design Tokens CG-03
   Ajouter à la suite du bloc CG-02 dans globals.css
═══════════════════════════════════════════════════ */

:root {

  /* ── FAMILLES ────────────────────────────────── */
  --font-sans: 'Inter', -apple-system, BlinkMacSystemFont, sans-serif;
  --font-mono: 'DM Mono', 'Fira Code', 'JetBrains Mono', monospace;

  /* ── TAILLES ─────────────────────────────────── */
  --text-xs:   10px;   /* labels mono UPPER, badges                */
  --text-sm:   11px;   /* légende, caption, aide, timestamps       */
  --text-base: 13px;   /* corps standard, lecture principale       */
  --text-md:   14px;   /* sous-titre, nav active, valeur de champ  */
  --text-lg:   18px;   /* titre de section                         */
  --text-xl:   22px;   /* valeur KPI, chiffre important            */
  --text-2xl:  28px;   /* titre de page uniquement                 */

  /* ── POIDS ───────────────────────────────────── */
  --font-light:    300;
  --font-regular:  400;
  --font-medium:   500;   /* principal — nav, labels, boutons sec.   */
  --font-semibold: 600;   /* principal — titres, noms, boutons prim. */
  --font-bold:     700;   /* titres de page et KPI uniquement        */

  /* ── LINE-HEIGHT ─────────────────────────────── */
  --lh-tight:   1.15;  /* 28px titres                              */
  --lh-snug:    1.30;  /* 18–22px sections                        */
  --lh-normal:  1.50;  /* 14px éléments UI                        */
  --lh-relaxed: 1.65;  /* 13px corps de texte                     */
  --lh-loose:   1.80;  /* mono labels, codes                      */

  /* ── LETTER-SPACING ─────────────────────────── */
  --tracking-tighter: -0.035em;  /* 28px titres                      */
  --tracking-tight:   -0.025em;  /* 18–22px sections                 */
  --tracking-snug:    -0.010em;  /* 14px sous-titres                 */
  --tracking-normal:   0;         /* corps standard 13px              */
  --tracking-wide:    0.06em;   /* mono labels discrets             */
  --tracking-wider:   0.12em;   /* badges UPPERCASE, section-labels */
}

/* ── BASE BODY ───────────────────────────────── */
body {
  font-family: var(--font-sans);
  font-size:   var(--text-base);
  line-height: var(--lh-relaxed);
  font-weight: var(--font-regular);
  -webkit-font-smoothing:    antialiased;
  -moz-osx-font-smoothing:  grayscale;
  text-rendering: optimizeLegibility;
}

/* ── UTILITAIRES ─────────────────────────────── */
.text-2xl  { font-size: var(--text-2xl);  font-weight: 700; letter-spacing: var(--tracking-tighter); line-height: var(--lh-tight); }
.text-xl   { font-size: var(--text-xl);   font-weight: 600; letter-spacing: var(--tracking-tight); }
.text-lg   { font-size: var(--text-lg);   font-weight: 600; letter-spacing: var(--tracking-tight); }
.text-md   { font-size: var(--text-md);   font-weight: 500; letter-spacing: var(--tracking-snug); }
.text-base { font-size: var(--text-base); font-weight: 400; line-height: var(--lh-relaxed); }
.text-sm   { font-size: var(--text-sm);   font-weight: 400; line-height: var(--lh-normal); }
.text-xs   { font-size: var(--text-xs);   font-weight: 500; letter-spacing: var(--tracking-wider);
              font-family: var(--font-mono); text-transform: uppercase; }
.truncate  { overflow: hidden; text-overflow: ellipsis; white-space: nowrap; max-width: 100%; }
