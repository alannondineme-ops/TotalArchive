01 — Système d'espacement

Base-4. Chaque valeur est un multiple de 4px.

Inspiré du système de Linear et Tailwind. La base-4 crée une harmonie optique naturelle entre tous les composants. Toute valeur hors de cette échelle est une anomalie visuelle — elle se voit immédiatement.

02 — Grille 12 colonnes

Toute mise en page est une subdivision de 12.

La grille 12 colonnes avec gap de 16px s'applique à la zone de contenu principale. Elle permet toutes les compositions : 1 col, 2 col, 3 col, 4 col, 6 col, et les asymétries 8+4, 9+3, 7+5.

03 — Shell applicatif

L'enveloppe de toute l'interface

Le shell est fixe et immuable. Topbar 48px, sidebar 240px ancrée à gauche, zone de contenu fluide à droite. C'est la grille structurelle du système — elle ne change pas selon les pages.

04 — Zones de composition

Chaque zone a ses règles de padding.

Le padding d'une zone n'est jamais arbitraire. Il est dicté par le rôle de la zone : plus un élément est "intérieur", plus son padding diminue. Cette logique crée la hiérarchie spatiale sans effort.

05 — Breakpoints

4 paliers. Une cible principale : 1280px+.

Le système est conçu desktop-first. Les archivistes travaillent sur grand écran. Le responsive existe mais n'est pas le cas nominal — il assure une dégradation gracieuse sur petits écrans sans sacrifier la densité cible.

768pxmd · tablet
1024pxlg · laptop
1280pxxl · cible ★
1536px2xl · large
sm
640px +
Mobile large. Sidebar cachée (drawer). Navigation bottom bar. Mise en page 1 colonne uniquement.
md
768px +
Tablette. Sidebar en overlay (toggle). Grille max 2 colonnes. Fonctionnalités admin limitées.
lg
1024px +
Laptop. Sidebar visible mais réduite à 200px. Grille 12 cols active. Interface complète.
xl ★
1280px +
Cible nominale. Sidebar 240px. Toutes fonctionnalités. Densité maximale. Conçu pour ce palier.

:root {

  /* ── ESPACEMENT BASE-4 ───────────────────────── */
  --space-1:   4px;
  --space-2:   8px;
  --space-3:  12px;
  --space-4:  16px;   /* padding card                */
  --space-5:  20px;
  --space-6:  24px;   /* padding content area        */
  --space-8:  32px;
  --space-10: 40px;
  --space-12: 48px;   /* hauteur topbar              */
  --space-16: 64px;
  --space-20: 80px;
  --space-24: 96px;

  /* ── LAYOUT SHELL ───────────────────────────── */
  --sidebar-width:   240px;
  --topbar-height:   48px;
  --content-padding: 24px;
  --grid-columns:    12;
  --grid-gap:        16px;

  /* ── Z-INDEX ─────────────────────────────────── */
  --z-base:     0;
  --z-raised:   10;
  --z-dropdown: 100;
  --z-sticky:   200;
  --z-overlay:  300;
  --z-modal:    400;
  --z-toast:    500;
  --z-grain:    9999;
}

/* ── SHELL LAYOUT ────────────────────────────── */
.app-shell {
  display: grid;
  grid-template-rows: var(--topbar-height) 1fr;
  grid-template-columns: var(--sidebar-width) 1fr;
  min-height: 100vh;
}

.app-topbar {
  grid-column: span 2;
  height: var(--topbar-height);
  position: sticky;
  top: 0;
  z-index: var(--z-sticky);
}

.app-sidebar {
  width: var(--sidebar-width);
  position: fixed;
  top: var(--topbar-height);
  left: 0;
  bottom: 0;
  z-index: var(--z-raised);
  background: var(--glass-bg);
  backdrop-filter: blur(var(--glass-blur));
  border-right: 1px solid var(--border-subtle);
  overflow-y: auto;
}

.app-content {
  margin-left: var(--sidebar-width);
  padding: var(--content-padding);
  min-height: calc(100vh - var(--topbar-height));
  overflow-y: auto;
}

/* ── BREAKPOINTS ─────────────────────────────── */
/* sm: 640px · md: 768px · lg: 1024px · xl: 1280px (cible) */
@media (max-width: 1024px) {
  .app-shell  { grid-template-columns: 200px 1fr; }
  .app-sidebar { width: 200px; }
  .app-content { margin-left: 200px; }
}
@media (max-width: 768px) {
  .app-shell  { grid-template-columns: 1fr; }
  .app-sidebar { transform: translateX(-100%); }
  .app-sidebar.open { transform: translateX(0); }
  .app-content { margin-left: 0; }
}
