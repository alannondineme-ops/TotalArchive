03 — Couleurs fonctionnelles

Success · Warning · Error · Info

Quatre couleurs fonctionnelles désaturées, volontairement retenues. Elles signalent sans alarmer. Leur saturation réduite les intègre dans l'atmosphère froide du système sans créer de dissonance chromatique.

Success
Document validé
#268245 · Vert sauge désaturé. Toast succès, badge validé, check état workflow.
Warning
Délai dépassé
#B07412 · Ambre désaturé. Alertes non critiques, workflows en retard.
Error
Erreur de validation
#9B322C · Rouge ardoise. Erreurs form, actions destructives, toasts d'échec.
Info
Synchronisation en cours
#2855A0 · Ardoise bleutée. Notifications neutres, états de chargement, info system.
04 — Thèmes Dark & Light

Les deux faces du système

La couleur d'accent Sage Slate fonctionne dans les deux modes. En dark, elle est vive sur fond sombre. En light, elle est plus profonde, avec ses nuances 600–700 qui offrent un meilleur contraste sur fond clair.

06 — Implémentation

globals.css — À copier tel quel

Ce bloc CSS est le fichier de tokens officiel du projet. Il est importé une seule fois à la racine. Toute valeur de couleur dans l'application passe par ces variables — jamais de valeur hex en dur.

CSS — globals.css · Design Tokens CG-02

   ARCHIVAGE NUMÉRIQUE — Design Tokens v1.0

   Ne pas modifier sans validation du référent design
═══════════════════════════════════════════════════ */
