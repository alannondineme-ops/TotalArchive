01 — Manifeste

Philosophie du design

Un système d'archivage public n'est pas un outil de divertissement. Il doit incarner la confiance, la précision et la durabilité — comme les documents qu'il conserve. Le design n'est pas décoration : il est infrastructure.

01 / Précise
Chaque pixel a une raison.
Aucun élément décoratif sans fonction. La hiérarchie visuelle est mathématique, prévisible. L'agent retrouve l'information en moins de 2 secondes — toujours au même endroit.
02 / Discrète
L'interface s'efface devant le contenu.
Couleurs désaturées, typographie compacte, animations furtives. L'interface ne crie pas. Elle murmure. Ce qui est important ressort non par emphase, mais par contraste maîtrisé.
03 / Fiable
Cohérence absolue, partout, toujours.
Un bouton primary est toujours identique. Un état d'erreur est toujours traité pareil. Le système de tokens garantit cette cohérence du premier composant au dernier écran.
02 — Règles fondamentales

Ce qui est permis. Ce qui est interdit.

Ces règles s'appliquent à tout composant, tout écran, tout état — sans exception.

Icônes SVG Lucide uniquement
Taille 14–16px. Stroke 1.5px. Jamais de glyphe ASCII, emoji, ou font-icon.
Border-radius discret ≥ 4px
Boutons et inputs : 4px. Cards : 6–8px. Modals : 8px. Pas de 12px ou plus.
Grain texturel sur tous les composants
SVG feTurbulence. Visible sur boutons (fort), cartes (moyen), fonds (très fort, effet brouillard).
Glassmorphism ciblé
Réservé à : sidebar, cards de données, toasts. Backdrop-blur 12–16px. Fond rgba(255,255,255,0.03–0.05).
Dégradés uniquement sur les graphiques
Sous les courbes statistiques. Transparence marquée. Jamais sur un bouton, card, ou fond d'écran.
Animations spring 150–200ms
cubic-bezier(0.34, 1.56, 0.64, 1) pour les apparitions. ease-out pour les disparitions.
Dégradés sur les éléments UI
Aucun background: linear-gradient sur boutons, inputs, cards, headers, ou fonds de page.
Grandes typographies ostentatoires
Titre max 28px. Body 12–13px. Label 10–11px. Jamais de hero text 40–60px dans l'application.
Ombres trop visibles
box-shadow en rgba(0,0,0,0.04–0.12) maximum. Simulation de profondeur Z uniquement.
ASCII / Emoji dans les interfaces
Interdit sur tout le territoire des interfaces. Aucune exception.

06 — Glassmorphisme

Usage ciblé de l'effet verre

Le glassmorphisme n'est pas appliqué partout. Il est réservé aux composants qui flottent au-dessus du contenu : sidebar, cards de KPI, toasts. Sur fond grain lourd, l'effet verre crée une profondeur sans artificiel.
