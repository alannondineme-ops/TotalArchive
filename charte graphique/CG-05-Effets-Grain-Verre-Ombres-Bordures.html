01 — Effet grain

Grain SVG feTurbulence — 3 niveaux codifiés

Le grain est l'empreinte sensorielle du système. Il transforme des surfaces numériques lisses en matières vivantes — comme une affiche sérigraphiée. Trois niveaux sont définis selon la visibilité souhaitée. Le grain global de la page (body::before) est en brouillard lourd, opacity 0.20.

02 — Glassmorphisme

Verre poli — 3 composants cibles

Le glassmorphisme est réservé aux composants qui flottent visuellement au-dessus du contenu : sidebar, cards de KPI, toasts. Il ne s'applique jamais aux boutons, inputs, tables ou fonds de page. Le grain renforce l'effet sur chaque surface vitrée.

03 — Ombres de profondeur

4 niveaux Z. Jamais décoratifs — toujours fonctionnels.

Les ombres simulent la hauteur Z d'un composant dans l'espace. Elles ne sont jamais utilisées pour "faire joli" — elles indiquent la hiérarchie de couches. Plus un composant est haut (modal > dropdown > card > base), plus son ombre est prononcée.

04 — Bordures & Border-radius

3 radius codifiés. 6 types de bordures.

Le border-radius est délibérément discret. On ne voit pas les arrondis — on les ressent. Minimum 4px sur tout élément interactif. La règle est ferme : aucun radius supérieur à 8px dans l'interface applicative.

05 — Reflet highlight

Le trait de lumière en bordure supérieure

Un liseré de lumière ultra-fin (1px) sur le bord supérieur des composants vitrés simule la réfraction de la lumière sur le verre. C'est un détail invisible à distance et saisissant de près. Il distingue un vrai composant glass d'une simple transparence basique.

06 — Export tokens

CSS Effects — À ajouter dans globals.css

CSS — globals.css · Effets CG-05
/* ═══════════════════════════════════════════════════
   EFFETS VISUELS — Design Tokens CG-05
   Ajouter à la suite des blocs CG-02/03/04
═══════════════════════════════════════════════════ */

:root {

  /* ── GRAIN ───────────────────────────────────── */
  /* Les SVG sont inline — copiez les URLs de ce fichier */
  --grain-url-light:  url("svg-feTurbulence baseFreq=0.72 opacity=0.10");
  --grain-url-medium: url("svg-feTurbulence baseFreq=0.88 opacity=0.15");
  --grain-url-heavy:  url("svg-feTurbulence baseFreq=0.95 opacity=0.32");
  --grain-size-lg:   180px;   /* fond page global           */
  --grain-size-md:   110px;   /* cards, panels              */
  --grain-size-sm:    65px;   /* boutons, badges            */

  /* ── GLASSMORPHISME ─────────────────────────── */
  --glass-sidebar-bg:   rgba(255, 255, 255, 0.030);
  --glass-card-bg:      rgba(255, 255, 255, 0.040);
  --glass-toast-bg:     rgba( 20,  22,  31, 0.820);
  --glass-border:       rgba(255, 255, 255, 0.090);
  --glass-border-toast: rgba(255, 255, 255, 0.100);
  --glass-blur-sm:  blur(12px);
  --glass-blur-md:  blur(14px);
  --glass-blur-lg:  blur(16px);
  --glass-highlight: linear-gradient(90deg, transparent, rgba(255,255,255,.12), transparent);

  /* ── OMBRES Z-DEPTH ─────────────────────────── */
  --shadow-sm: 0 1px  3px rgba(0,0,0,.20), 0 1px  2px rgba(0,0,0,.12);
  --shadow-md: 0 4px 12px rgba(0,0,0,.25), 0 2px  4px rgba(0,0,0,.12);
  --shadow-lg: 0 8px 24px rgba(0,0,0,.30), 0 4px  8px rgba(0,0,0,.14);
  --shadow-focus: 0 0 0 2px var(--bg-base), 0 0 0 4px var(--accent-500);
  --shadow-focus-error: 0 0 0 2px var(--bg-base), 0 0 0 4px rgba(155,50,44,.70);
}

/* ── MIXINS GRAIN (pseudo-elements) ──────────── */
.grain-global { /* body::before */
  position: fixed; inset: 0; z-index: 9999; pointer-events: none;
  background-size: var(--grain-size-lg);
  opacity: 0.20; mix-blend-mode: overlay;
}
.grain-card::after   { background-size: var(--grain-size-md); opacity: 0.13; }
.grain-button::after { background-size: var(--grain-size-sm); opacity: 0.35; }

/* ── MIXIN GLASS ──────────────────────────────── */
.glass-card {
  background:      var(--glass-card-bg);
  backdrop-filter: var(--glass-blur-md);
  border:          1px solid var(--glass-border);
}
.glass-card::after { /* highlight top */
  content: ''; position: absolute;
  top: 0; left: 0; right: 0; height: 1px;
  background: var(--glass-highlight);
}

/* ── FOCUS VISIBLE ───────────────────────────── */
*:focus-visible {
  outline: none;
  box-shadow: var(--shadow-focus);
}
