Règle fondamentale — Dégradés
Les dégradés sont autorisés exclusivement sous les courbes statistiques (fill area). Ils sont interdits partout ailleurs : boutons, cards, fonds, headers, inputs, barres. Transparence décroissante obligatoire vers 0 sur l'axe vertical.
01 — Sparklines

Mini-sparklines — Cards KPI

Sparklines SVG inline dans les cards KPI glassmorphisme. Courbe accent-400 stroke 1.5px + dégradé sous la courbe (seul usage autorisé). Pas d'axes, pas de labels — données relatives uniquement.
