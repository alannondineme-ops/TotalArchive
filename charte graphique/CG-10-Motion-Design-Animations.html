01 — Courbes & Timings

Courbes d'accélération & durées autorisées

Le système utilise 3 courbes uniquement. Toutes les durées restent entre 100ms et 250ms. Aucune animation UI ne dépasse 250ms — au-delà l'interface est perçue comme lente en usage intensif 8h/jour.

02 — Entrées & Sorties

Patterns d'entrée et de sortie

Entrées : scale+opacity ou translateY+opacity · Spring 200ms. Sorties : opacity seule ou scale minimal · Ease-out-fast 160ms. Les sorties doivent toujours être plus rapides que les entrées pour ne pas bloquer le flux de travail.

Scale + Opacity
Modals, panels principaux
@keyframes entryScale { from { opacity: 0; transform: scale(0.94) translateY(6px); } } /* 200ms spring */
TranslateY + Opacity
Rows, nav items, dropdowns
@keyframes entryUp { from { opacity: 0; transform: translateY(10px); } } /* 180ms ease-out-fast */
Sortie — Opacity seule
Toasts, alertes, dropdowns
/* 160ms ease-out-fast */ from { opacity: 1; transform: scale(1) } to { opacity: 0; transform: scale(0.97) translateY(-6px) } /* Toujours + rapide qu'entrée */

03 — Stagger

Staggered reveals — listes & grilles

Délai inter-items : 40ms. Maximum 6 items avec stagger (au-delà : pas de décalage pour raisons de performance). Les éléments les plus importants s'animent en premier (hiérarchie temporelle).

Démo interactive — Liste de documents archivés
Code CSS — Stagger 40ms × n
@keyframes staggerIn { from { opacity: 0; transform: translateY(8px); } to { opacity: 1; transform: translateY(0); } } .stagger-item { animation: staggerIn 200ms var(--ease-out-fast) both; } .stagger-item:nth-child(1) { animation-delay: 0ms; } .stagger-item:nth-child(2) { animation-delay: 40ms; } .stagger-item:nth-child(3) { animation-delay: 80ms; } .stagger-item:nth-child(4) { animation-delay: 120ms; } .stagger-item:nth-child(5) { animation-delay: 160ms; } .stagger-item:nth-child(6) { animation-delay: 200ms; } /* Au-delà de 6 items : supprimer le stagger */
